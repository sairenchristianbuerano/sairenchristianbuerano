## 🚀 Featured Work

### Trustabl CI/CD Suite — AI agent security scanning on every major platform

Designed, built, and published the full CI/CD integration lineup for [Trustabl](https://github.com/trustabl/trustabl), a static reliability/safety analyzer for AI agent repos (Claude Agent SDK, OpenAI Agents SDK, Google ADK, MCP).
